HARDWARE INTEGRATION

Bridge to physical nodes

Connect a USB serial controller with newline-delimited JSON. Buttons become hazard events; each notifier receives its own guidance command.

Bedroom ANODE_ROOM_AREADY
Bedroom BNODE_ROOM_BREADY
Bedroom CNODE_ROOM_CREADY

Simulator is active. Chrome or Edge on localhost supports the serial bridge.

ONE SMALL CONTRACT

Events in. Guidance out.

{"type":"hazard","node":"KITCHEN","active":true}
{"type":"hazard","node":"WEST_HALL","active":true}

Each change sends a command for every notifier:

{"type":"guidance","node":"ROOM_A",
 "message_id":"ALERT_ROOM_A_EAST_EXIT_KITCHEN_WEST_HALL",
 "exit":"EAST_EXIT",
 "text":"Fire alert. From Bedroom A..."}

See docs/HARDWARE.md for wiring assumptions, valid IDs and testing steps. The browser speaks guidance locally; a microcontroller can map message IDs to cached audio.
